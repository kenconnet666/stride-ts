# 路线图

**要做成什么**：一个在浏览器里运行的**一站式创作工作台**——同一套引擎和编辑器，既能做 3A 级的大型游戏，也能做短视频、动画片、剧集这类成片（画面以现在接近电影的 3A 大作为标准）。核心能力是**在编辑器里从零造出大型世界、让它像真实世界一样运转**；资源尽量是"怎么生成"的描述（矢量、参数化），扫描的材质、照片、泼溅这类采样数据也能导入使用。人和 agent 都能用它创作。起点是 Stride 引擎的 TypeScript 孪生版，目标是比 Stride 做得更好。

**怎么读这张表**：从上往下是大致的先后，不是固定的——执行中按需要调整（后面的某一块先被用到就提前做，前面的暂时用不上就往后放），调整了在"备注"里写一句为什么。大阶段是一类目标，小阶段是其中能单独验收的一块。状态：✅ 做完（日期）　▶ 正在做　◐ 做了一部分　☐ 还没做。"过程"一列是小阶段里的一步步：做完的打 ✅，没做的 ☐。"备注"一列记临时的笔记（遇到的问题、量到的数字、接下来试什么）、依赖和顺序的说明、谁在哪天定的；小阶段做完后笔记精简成结论。各项的技术细节和做完时的结论在 [stages.md](stages.md)，每一步的详细经过在 [progress-log.md](progress-log.md)，执行中的决定在 [decisions.md](decisions.md)。
