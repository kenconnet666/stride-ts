# short-film

路线图 F4 验收用的 30 秒短片（docs/roadmap.md 的"正在做和下一步"F 组第 4 项）：在编辑器里搭场景、做时间轴、出片（横屏和 9:16 竖屏）。用 `stride-editor new` 建的工程，开发服务器 `pnpm dev`（端口 5226），编辑器在 `/__stride/editor/`。

素材来源：

- `Characters/RobotExpressive`：Tomás Laulhé（Quaternius）的 Robot Expressive，Don McCurdy 加了表情形变、转成 glTF，取自 three.js 的示例（`examples/models/gltf/RobotExpressive`），CC0 1.0。在编辑器里拖进资源浏览器导入（骨架、14 个动画剪辑、形变目标）。
